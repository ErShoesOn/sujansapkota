# Bidder Registration Checklist

**General guidance for firms preparing to register on PPMO's e-GP / Bolpatra portal.**

> Requirements and portal steps can change. Use this list only as a starting point and follow the current instructions and published checklist on the official portal: https://bolpatra.gov.np/

## Firm information

- [ ] Registered firm name exactly as per official registration documents.
- [ ] Registration date, registration number and issuing office.
- [ ] Address and contact details used consistently everywhere.
- [ ] PAN/VAT information, where applicable.
- [ ] Firm type and category details as registered.

## People and authorisation

- [ ] Authorised representative(s) identified.
- [ ] Contact mobile number and email address that the firm can access.
- [ ] Identity and authorisation documents prepared.
- [ ] Role of each representative decided (who prepares, who submits, who approves).

## Documents commonly requested

- [ ] Firm registration / trade licence.
- [ ] PAN/VAT registration documents.
- [ ] Tax clearance or related documents if requested.
- [ ] Bank account information, if required.
- [ ] Representative authorisation documents.
- [ ] Any other document listed in the current official registration checklist.

## Account security

- [ ] Strong password set and stored securely.
- [ ] Two-Factor Authentication configured if available/required.
- [ ] Digital signature or certificate requirements understood.
- [ ] Recovery information updated and accessible.

## After registration

- [ ] Account verified/activated as per the current process.
- [ ] Test login completed by both the firm and the authorised representative.
- [ ] Portal notifications and email settings checked.
- [ ] Team briefed on never sharing login credentials.
